# 一個網址，AI 幫你做品牌廣告（Van在途中 Demo 1）

這是我在影片〈AI 剪片實測：Opus 5.5 一句話剪出品牌廣告〉裡 Demo 1 的完整做法。免費，直接拿去用。

📺 影片：https://www.youtube.com/@vaninaction

---

## 你需要
- **Claude Code**（或其他能裝 skill 的 AI 工具）
- **Node.js**：到 nodejs.org 下載安裝
- 一個網址：你的網站、YouTube 頻道或社群主頁

## 三步開始

**1. 裝 HyperFrames（免費開源）**
在終端機輸入：
```
npx hyperframes skills
```
或者直接對 Claude Code 說：「幫我裝好 HyperFrames：https://github.com/heygen-com/hyperframes」

**2. 裝我的 skill（可選）**
把這個資料夾裡的 `brand-ad-from-url` 放進 `~/.claude/skills/`。
或者直接對 Claude Code 說：「幫我把這個 skill 裝起來：（這個頁面的網址）」

**3. 對 AI 說一句話**
> 用 HyperFrames，把這個網址做成一支 30 秒的品牌廣告：〔你的網址〕

## 我真實的三輪對話

| 回合 | 我說了什麼 | AI 做了什麼 |
|---|---|---|
| 第 1 版 | 給它我的頻道網址，說要一支有質感的品牌短片 | 自己去抓頻道頁、縮圖、頭像，做了一版橘色海報風 |
| 第 2 版 | 「還不錯，但不夠性感……應該聚焦在影片上」 | 從我 6 支影片裡挑了 12 個片段，改成暗色風 |
| 第 3 版 ✅ | 「縮圖牆太怪、字太小、要多一點動態、暗色背景加一點我的品牌橘」 | 字放大、動態變多、加上品牌色，過關 |

**我總共只說了三次話。我做的事只有一件：說我喜不喜歡。**

---

## 5 個心法
1. **先給素材，不要先給指令**：網址、數據、影片先丟給它
2. **講感覺，不要講參數**：「不夠性感」「字太小」就夠了
3. **不滿意就退件**：兩三輪很正常
4. **讓它自己檢查**：叫它截圖看完再交給你
5. **最後一步自己來**：配樂、微調，在你習慣的剪輯軟體裡加

## 誠實說缺點
- 它不會自己配樂，音樂要自己加
- 檔案放在 Google 雲端硬碟裡會裝不起來，請放在電腦本機的資料夾
