# Brand ad from one URL (Van在途中 Demo 1)

You are making a short brand ad from a single URL, for a non-technical small-business owner. They will judge by feel, not by parameters.

## Before you start
- HyperFrames must be installed. If not, run `npx hyperframes skills` and follow the `hyperframes` skill as the entry point for building and rendering.
- If the project folder is inside Google Drive / OneDrive / Dropbox, build in a local folder instead (cloud-sync folders break installs), then copy the finished MP4 back.

## Steps
1. **Collect the material yourself.** Open the URL. Capture screenshots, logo, profile photo, brand colours, key phrases. For a YouTube channel, also grab thumbnails and short clips from their best videos.
2. **Show their real work, not a poster.** The ad should be built around their actual content (videos, products, results). A text-only "orange poster" style was rejected in the original test as "not sexy".
3. **Defaults that worked:**
   - 20–40 seconds, 16:9 (also offer 9:16)
   - dark background with the brand's own accent colour
   - big text (it must be readable on a phone), lots of motion, fast cuts
   - end on the name + one line + the URL
   - no music; tell the user to add it in their editor
4. **Render, then check your own work.** Take snapshots, look for small text, odd layouts or empty frames, and fix them before showing anything.
5. **Ask for feedback in plain words.** e.g. "Tell me what feels off: too plain, too slow, text too small, not your style?" Translate their feelings ("not sexy enough", "more motion", "add my colour") into design changes yourself. Never ask them for technical values.
6. Iterate. Two or three rounds is normal.
